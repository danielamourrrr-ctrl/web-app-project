# Multi-Page Web Application Project - Apex Digital Solutions

## Project Overview
This is a fully responsive, multi-page web application built for **Apex Digital Solutions** (a technical consulting business) using HTML5, CSS3, JavaScript (ES6+), and Bootstrap 5.

## Tech Stack
* HTML5 / CSS3 (Custom responsive structures, variables, and transition frameworks)
* Bootstrap 5 (Fluid layouts, dynamic form inputs, grid arrays, and nav components)
* JavaScript (ES6+ client-side application logic and dynamic DOM manipulation)

## Live Interactivity Features
1. **Dynamic Contact Form Validation:** Processes user consultation inputs, validates syntax routing via email regex patterns, and returns instant interactive alert notifications without page breaks.
2. **Real-Time FAQ Search Filter:** Instantly evaluates user text strings typed into the search bar, tracking matches across titles and paragraph text block containers to conditionally filter visibility instantly.
3. **Dynamic Footer Auto-Copyright Year:** Programmatically queries the system date parameters to update the copyright text instantly across all page templates.
4. **Dynamic Injectable Scroll-to-Top:** Automatically instantiates, styles, and injects a smooth-scrolling floating anchor link into the active DOM hierarchy when vertical scroll metrics cross viewport margins.
